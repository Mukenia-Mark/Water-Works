# Water Works Billing System 💧

A billing system for managing water utility customer accounts, readings, and invoicing.

## 🌐 Live Demo
[waterworksbillingsystem.netlify.app](https://waterworksbillingsystem.netlify.app)

## ✨ Features
- Customer account management
- Water reading tracking
- Billing and invoicing system
- Customer portal access
- Administrative dashboard

## 🛠️ Tech Stack
- **Frontend:** JavaScript (59.1%), CSS (29.4%), HTML (11.5%)
- **Build Tool:** Vite
- **Code Formatter:** Prettier
- **Deployment:** Netlify
- **License:** MIT

## 📁 Project Structure
```
├── css/ # Stylesheets
├── js/ # JavaScript files
├── public/ # Static assets
├── bill-customer.html # Billing page
├── customer-management.html # Customer management
├── new-customer.html # New customer registration
├── index.html # Home page
├── vite.config.js # Vite configuration
├── netlify.toml # Netlify configuration
└── LICENSE # MIT License
```

## 📄 Pages
- **Home** (`index.html`) - Main dashboard
- **Customer Management** (`customer-management.html`) - Manage customer accounts
- **New Customer** (`new-customer.html`) - Register new customers
- **Bill Customer** (`bill-customer.html`) - Generate customer bills

## 🚀 Installation
```bash
# Clone the repository
git clone https://github.com/Mukenia-Mark/Water-Works.git

# Navigate to project directory
cd Water-Works

# Install dependencies
npm install

# Run development server
npm run dev
```
